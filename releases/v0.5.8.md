# Blue&Me v0.5.8 NAVFIX — versão estável de referência

Versão anterior ao WheelControl, preservada separadamente da v0.6.1-beta.1. O utilizador confirmou o funcionamento desta base no Alfa Romeo MiTo. A designação estável refere-se à instalação de referência; não representa validação universal de veículos, telemóveis ou instalações limpas.

## Incluído
- Motor NAVFIX v0.5.8 original, sem alterações.
- Instalador, testes offline e rollback originais.
- Sem deteção dos botões Next/Previous e sem WheelControl.

## Instalação
Este ZIP é um patch para a instalação antiga v0.5.6 que utiliza `blueandme-bt-v056.service`, não um instalador completo para cartões novos. Não se aplica diretamente à versão comunitária `blueandme-bt.service`.

Descomprime o ZIP, abre a pasta `navfix-v058` e lê `README-v058.pt-PT.md`. Ejeta primeiro a unidade USB no leitor. O instalador exige OverlayFS desativado e verifica o hash da base original.

```bash
sudo bash install-navfix-v058.sh /CAMINHO/DA/PONTE
```

Substitui o caminho pela pasta da instalação antiga, que contém `start_bt_v056.sh` e `live_bt_nbd_v056.py`. Se NAVFIX v0.5.8 já estiver instalada e funcional, não a reinstales.

## Rollback da NAVFIX para v0.5.6
```bash
sudo bash rollback-navfix-v058.sh /CAMINHO/DA/PONTE
```
Requer o backup criado pelo instalador.

## Se já tens a beta instalada
Este ZIP não remove WheelControl nem faz downgrade automático da beta. Para ficar apenas com a base de áudio NAVFIX, desativa primeiro a automação:
```bash
sudo python3 /opt/blueandme-wheel-v060/wheelctl.py auto-off
```
Podes parar e desativar apenas o serviço auxiliar:
```bash
sudo systemctl disable --now blueandme-wheel-v060.service
```
Isto conserva a NAVFIX e os ficheiros WheelControl para eventual recuperação.

## Validação e diferenças
O funcionamento foi relatado no MiTo; os testes offline não substituem testes físicos. A beta permanece disponível separadamente, acrescentando WheelControl v0.6.1 experimental com intervalo mínimo de 9 segundos entre eventos.

Os arquivos automáticos "Source code" do GitHub correspondem ao commit do repositório, que também inclui o código beta numa pasta separada. Para este patch utiliza o asset `BlueAndMe_NAVFIX_v058.zip`.
