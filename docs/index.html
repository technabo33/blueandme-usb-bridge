01 / ARQUITETURA

O carro vê uma pen.
Tu ouves Bluetooth.

O segredo está em servir dados de áudio em tempo real através de ficheiros WAV virtuais, sem criar gravações permanentes.

01

Receção A2DP

O telemóvel liga ao Pi através de Bluetooth. O BlueALSA disponibiliza áudio PCM a uma aplicação Python.

02

FAT32 virtual

Uma imagem sparse contém 48 WAV, mas o conteúdo áudio é preenchido durante as leituras USB a partir de um buffer na RAM.

03

USB mass storage

O nbdkit e o controlador g_mass_storage apresentam ao rádio uma unidade FAT32 apenas de leitura.

44,1 kHz16-bit stereo PCMBlueZ + BlueALSAPython + nbdkitOverlayFS opcional
02 / COMEÇAR

Uma instalação
que podes replicar.

Preparámos um pacote público com o motor testado, instalador, gerador da imagem FAT32, guia de emparelhamento e ferramentas de diagnóstico.

  1. Prepara o Raspberry.Raspberry Pi OS Lite 32-bit, Wi-Fi, SSH e um microSD novo.
  2. Instala o projeto.Clona o repositório, executa o instalador e reinicia.
  3. Emparelha o telemóvel.Autoriza-o no Bluetooth e define-o como prioritário.
  4. Testa a USB e protege o SD.Valida a reprodução antes de ativar OverlayFS.
Abrir guia completo de instalação ↗
raspberrypi / terminal
# Raspberry Pi OS Lite (32-bit)
$ sudo apt update
$ sudo apt install -y git
$ git clone \
    https://github.com/technabo33/blueandme-usb-bridge.git
$ cd blueandme-usb-bridge
$ sudo bash scripts/install.sh
$ sudo reboot

Depois do reboot, segue o guia para emparelhar o teu telemóvel antes de ouvir música.

04 / PERGUNTAS

As respostas essenciais.

Preciso de alterar o rádio ou instalar AUX?

Não. A ideia é usar a mesma entrada USB que já aceita uma pen. A compatibilidade depende do leitor do automóvel.

O projeto funciona em qualquer Blue&Me?

Não há garantia. O sistema de referência foi um Alfa Romeo MiTo 2010. Outros automóveis e versões de Blue&Me precisam de testes específicos.

O áudio é gravado no microSD?

Não. O motor entrega amostras PCM a partir de um buffer na RAM. A imagem FAT32 é estática, sparse e exportada como apenas de leitura.

Posso desligar a ignição sem um shutdown manual?

O OverlayFS e a proteção da partição de arranque reduzem o risco de corrupção, mas não substituem uma alimentação de 5 V estável nem garantem resistência a todas as falhas.

Os botões do volante controlam Spotify?

Ainda não. Controlos AVRCP através de padrões de leitura USB são uma ideia de investigação futura, não uma funcionalidade atual.

Quanto custa e posso contribuir?

O software está disponível gratuitamente sob licença MIT. Necessitas de Raspberry Pi, microSD, cabo e alimentação. Podes abrir issues e pull requests no GitHub.
